# Bark Reminder

一个轻量的网页声音提醒工具。填写提醒事项，选择多久后提醒，到时间后播放脉冲提示音、弹出确认窗口，并在获得权限时尝试发送系统通知。

页面使用原生 HTML、CSS 和 JavaScript 编写，无需安装依赖或构建，任务保存在当前浏览器中。

## 开始使用

直接用浏览器打开 `index.html`，或在项目目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

访问 <http://127.0.0.1:8765/index.html>。停止本地服务时，在终端按 `Control + C`。

1. 输入提醒事项；留空时会使用「未命名提醒」。
2. 选择 **5、15、25 或 45 分钟**，默认 5 分钟；也可选择 **3秒（测试）**，快速检查到期提醒。
3. 如需按所选间隔持续提醒，勾选循环设置。
4. 点击「试听」，检查浏览器是否能播放提示音。
5. 点击「添加声音提醒」。浏览器若询问通知权限，可按需允许。
6. 保持页面打开、设备处于唤醒状态，等待提醒。

## 提醒如何工作

可同时添加多项提醒，每项显示剩余时间。网页标题也会显示最近一项提醒的倒计时。

到期时，页面循环播放原版脉冲警报，最长 5 分钟并弹出确认窗口：

| 操作 | 当前行为 |
| --- | --- |
| 弹窗选择 +5、+10、+15 分钟 | 从点击时起重新计时，并关闭弹窗 |
| 单次提醒点击「完成了！」 | 删除该提醒并关闭弹窗，不保留完成记录 |
| 循环提醒点击「完成了！」 | 关闭弹窗，保留下一轮提醒 |
| 任务卡片选择 +5分、+15分 | 从点击时起重新计时，不是在原到期时间上累加 |
| 点击任务卡片的 ✕ | 删除该提醒 |

**循环设置按分钟间隔重复。** 虽然页面标签写着「每天 / 到期后自动循环提醒」，当前实现是每隔所选的 5、15、25 或 45 分钟提醒，并非每天固定时间提醒。循环任务在到期时就会安排下一轮，不等待你点击完成。

单次提醒到期后若未处理，会自动安排一分钟后再次提醒，直到完成、手动推迟或删除。

## 声音、通知与运行限制

- 提醒和试听均循环播放原版脉冲警报，最长 5 分钟；点击「停止铃声」可静音，处理当前提醒时也会停止。
- 浏览器可能限制自动播放。试听成功不代表后台到期时一定能发声，仍需在实际使用的浏览器中确认。
- 添加提醒时会尝试请求系统通知权限。通知能否出现取决于浏览器支持、访问方式、权限和系统设置；本地预览建议使用上面的 localhost 地址。
- 当前通知没有配置点击后返回或聚焦主页面的行为。
- 页面每秒检查到期时间。后台标签页可能被限速，提醒可能延迟。
- 关闭网页、退出浏览器或设备休眠期间不能保证提醒；重新打开后，保存的逾期任务会在计时检查时触发。
- 多项任务同时到期时会分别触发提示音和通知，但共用一个确认弹窗，后处理的任务会覆盖弹窗内容，当前没有逐项排队机制。

## 数据保存

任务保存在当前浏览器的 `localStorage` 中，存储键为 `bark_tasks`。保存内容包括任务名称、提醒间隔、是否循环和下次到期时间。

- 无需账号，任务不上传服务器，也不跨浏览器或设备同步。
- 刷新页面后会恢复任务；已完成或删除的任务不保留历史记录。
- 清除网站数据会删除任务；隐私模式中的数据可能在会话结束后被清除。
- 直接打开文件、使用 localhost、切换端口，可能对应不同的存储空间。建议固定一种访问方式。
- 多个标签页之间没有实时同步，建议只打开一个页面。
- 当前版本不读取旧版的 `zuolemei.tasks.v1` 数据，也没有自动迁移或导入导出功能。
- 当前未提供存储异常恢复机制；浏览器禁用存储或保存内容损坏时，页面可能无法正常工作。

## 项目文件

```text
zuolemei/
├── index.html       # 当前 Bark Reminder：页面、样式及全部逻辑
├── index-old.html   # 保留的旧版页面
├── alarm.wav        # 历史音频文件，当前页面未引用
├── need.md          # 项目需求笔记
└── README.md        # 使用说明
```

当前页面没有第三方依赖、CDN、后端或数据库。提示音由 Web Audio API 实时生成，单独复制 `index.html` 即可使用。

页面底部的「解锁 Pro」目前仅显示预告弹窗。AI 语音喊话、自定义音频上传和订阅支付尚未实现，弹窗中的价格是预告文案。

## 手动检查

建议用可删除的测试提醒验证：

1. 点击「试听」，确认能听到脉冲警报，并确认「停止铃声」可以停止播放。
2. 添加提醒，检查任务数量、卡片倒计时和网页标题是否更新。
3. 点击卡片上的「+5分」，确认倒计时重设为约 5 分钟；刷新后确认任务仍在。
4. 等待单次提醒到期，检查声音、弹窗和已授权的系统通知；点击「完成了！」后确认任务被删除。
5. 到期后选择弹窗中的延后时间，确认弹窗关闭且倒计时重设。
6. 不处理到期的单次提醒，检查约一分钟后是否再次提醒。
7. 添加循环提醒，确认到期后自动进入下一轮，点击完成仍保留任务；点击 ✕ 后删除。
8. 将页面放到后台，检查实际提醒延迟和声音表现；关闭页面至逾期后重新打开，检查任务恢复。
9. 在窄屏下检查表单、任务卡片和弹窗是否可操作。

本说明根据当前源代码整理，以上清单不代表已完成真实浏览器交互、系统通知验证或声音试听。
